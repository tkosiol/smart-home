# ADR-0019: Lizenz AGPL-3.0-only

- Status: angenommen
- Datum: 2026-10-11

## Kontext

Das öffentliche Repository hatte keine Lizenz und war damit rechtlich nicht nutzbar. Das Projekt ist eine selbst gehostete Web-App.

## Entscheidung

AGPL-3.0-only für das gesamte Repository.

## Konsequenzen

Freie Nutzung, Änderung und Selbsthosting; wer eine veränderte Version als Netzwerkdienst anbietet, muss den Quellcode offenlegen. Neue Abhängigkeiten werden auf Lizenzkompatibilität geprüft. Ein späterer Lizenzwechsel ist nur möglich, solange keine externen Beiträge vorliegen.

Details: `docs/superpowers/specs/2026-10-11-self-hosting-and-license-design.md`, Abschnitt 5.

# Lizenz AGPL-3.0-only – Umsetzungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Das Repository steht unter AGPL-3.0-only, und die CI verhindert, dass Abhängigkeiten mit unverträglichen Lizenzen hineinkommen.

**Architecture:** Offizieller Lizenztext als `LICENSE`, Lizenzfeld in allen `package.json`, Hinweis in der README. Ein kleines Node-Skript in `tools/lint-config` prüft die Ausgabe von `pnpm licenses list --json -r` gegen eine Freigabeliste und läuft im CI-Job `verify`.

**Tech Stack:** Node 24, pnpm 12, Vitest 5.

**Spec:** `docs/superpowers/specs/2026-10-11-self-hosting-and-license-design.md` (Abschnitt 5), ADR-0019

## Global Constraints

- Lizenz exakt `AGPL-3.0-only` (SPDX), Lizenztext unverändert von `https://www.gnu.org/licenses/agpl-3.0.txt`.
- Freigegebene Lizenzen für Abhängigkeiten: `MIT`, `MIT-0`, `Apache-2.0`, `ISC`, `BSD-2-Clause`, `BSD-3-Clause`, `0BSD`, `BlueOak-1.0.0`, `Unlicense`, `CC0-1.0`, `Python-2.0`, `MPL-2.0`, `CC-BY-4.0` (nur Daten, z. B. Browser-Kompatibilitätstabellen).
- Eigene Pakete (`@smart/*`, Root `smart-home`) tragen `AGPL-3.0-only`.
- Code/Kommentare Englisch, Doku Deutsch, Conventional Commits, keine KI-Attribution; Arbeit auf Branch `docs/self-hosting-and-license` (enthält bereits den Design-Nachtrag).

## Review Focus

1. **Zusammengesetzte Lizenzausdrücke** (`(MIT OR Apache-2.0)`, `(Apache-2.0 AND BSD-3-Clause)`): OR ist erlaubt, wenn eine Alternative erlaubt ist; AND nur, wenn alle erlaubt sind. → Tests in Task 2, Schritt 1.
2. **Unbekannte oder fehlende Lizenz** (`Unknown`, leer): muss die CI rot machen und das Paket nennen. → Task 2, Schritt 1.
3. **Eigene Pakete ohne Lizenzfeld** (neues Workspace-Paket vergessen): muss auffallen. → Task 1, Schritt 1 (Repo-Test prüft alle Workspace-`package.json`).
4. **Veränderter oder falscher Lizenztext** (z. B. GPL statt AGPL): → Task 1, Schritt 1 (Kopfzeilen-Prüfung).
5. **Ausgabeformat von `pnpm licenses` ändert sich**: Das Skript darf dann nicht stillschweigend „ok“ melden. → Task 2, Schritt 1 (leere/ungültige Eingabe = Fehler).

`tools/lint-config/licenses/check-licenses.mjs`:

```js
#!/usr/bin/env node
// Fails CI when a dependency's license is not compatible with this AGPL-3.0-only project.
// Input: `pnpm licenses list --json -r` on stdin.
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';

const ALLOWED = new Set([
  'MIT',
  'MIT-0',
  'Apache-2.0',
  'ISC',
  'BSD-2-Clause',
  'BSD-3-Clause',
  '0BSD',
  'BlueOak-1.0.0',
  'Unlicense',
  'CC0-1.0',
  'Python-2.0',
  'MPL-2.0',
  'CC-BY-4.0',
]);
const OWN_LICENSE = 'AGPL-3.0-only';
const isOwnPackage = (name) => name === 'smart-home' || name.startsWith('@smart/');

/** SPDX subset: identifiers combined with OR / AND, optionally in one pair of parentheses. */
export function isAllowed(expression) {
  const trimmed = (expression ?? '').trim().replace(/^\((.*)\)$/, '$1');
  if (trimmed === '') return false;
  if (/\sOR\s/.test(trimmed)) return trimmed.split(/\s+OR\s+/).some((part) => isAllowed(part));
  if (/\sAND\s/.test(trimmed)) return trimmed.split(/\s+AND\s+/).every((part) => isAllowed(part));
  return ALLOWED.has(trimmed);
}

export function findViolations(report) {
  const violations = [];
  for (const [license, packages] of Object.entries(report)) {
    const offending = packages
      .map((pkg) => pkg.name)
      .filter((name) => !(isAllowed(license) || (license === OWN_LICENSE && isOwnPackage(name))));
    if (offending.length > 0) violations.push({ license, packages: offending });
  }
  return violations;
}

function main() {
  let report;
  try {
    report = JSON.parse(readFileSync(0, 'utf8'));
  } catch {
    console.error('check-licenses: input is not the JSON output of `pnpm licenses list --json -r`');
    process.exit(1);
  }
  const total =
    report && typeof report === 'object' && !Array.isArray(report)
      ? Object.values(report).reduce(
          (sum, packages) => sum + (Array.isArray(packages) ? packages.length : 0),
          0,
        )
      : 0;
  if (total === 0) {
    console.error('check-licenses: report contains no packages – refusing to report ok');
    process.exit(1);
  }
  const violations = findViolations(report);
  if (violations.length > 0) {
    for (const { license, packages } of violations) {
      console.error(`license not allowed: ${license} – ${packages.join(', ')}`);
    }
    process.exit(1);
  }
  console.log(`licenses ok (${total} packages)`);
}

if (process.argv[1] === fileURLToPath(import.meta.url)) main();
```
